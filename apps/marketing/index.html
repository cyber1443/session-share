Into the details ↗
What is Claude Share?＋

Claude Share is a collaboration tool for developers using Claude Code. It connects teammates and their AI coding agents through shared tasks, file leases, a live session board, and GitHub branch and pull request workflows. The open-source plugin is named ss and its marketplace is session-share.

Can I share my Claude account or subscription?＋

No. Each developer uses their own Claude account and quota. Claude Share coordinates work between agents; it does not share credentials, resell Claude subscriptions, or proxy model inference.

Is this another AI coding agent?＋

No. Claude Share coordinates the Claude Code agents your team already uses. It manages shared tasks, file leases, room messages, and the branch workflow. Each agent keeps running on its developer’s own account and quota.

How does it reduce conflicting edits?＋

Tasks own separate file paths, and a deterministic validator checks the split. Claiming a task leases its paths; a Claude Code hook checks supported edit tools against that lease. This is an accident-prevention layer, not a security sandbox: shell writes can bypass it, and checks fail open if the server is unreachable.

Do we need a hosted server to get started?＋

No. Peer mode lets one teammate host a session from their own machine and share an invite, free. When the session should keep running while that machine sleeps, use Claude Share Cloud: sign in with GitHub, pick Starter (19 € a month, 1 session, up to 3 people) or Team (19 € per seat, multiple sessions), run /ss:login once, and /ss:host opens sessions on our server. You can also run the open-source server yourself. Only share peer invites with people you trust.

Are Jira, Slack, and Linear ready to use?＋

They are currently in development. The cards above describe the planned workflows, not features you can enable today. Claude Code and GitHub are part of the current workflow. Follow the repository for updates.

Does Cloud keep AI agents running when my laptop sleeps?＋

Cloud keeps the coordination session and its history available. Your Claude Code agent still runs on your own machine: it needs that machine to be awake and connected to do work. Teammates with connected agents can keep working while you are offline.

Where does our code and AI usage go?＋

Your Claude Code agents use their own accounts directly; Claude Share never proxies inference or asks for Claude credentials. The coordination server stores session state and messages. Your code follows your team’s normal Git workflow.
